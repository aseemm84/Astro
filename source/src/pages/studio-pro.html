How this page works

Most studio tools are a gallery: somebody writes a dozen animations and you pick one. This is not that. Every quantity the engines compute is published here with a declared shape — a longitude, a magnitude, a division of the circle, a set of pairs, an interval of time, a quantity that varies with the instant — and a small set of composers each declare which shapes they can draw.

So a composer that draws two longitudes and the angle between them will draw the Sun and the Moon, the Lagna and the Arūḍha Lagna, a daśā lord and its dispositor, or a transiting graha against its own natal place, without knowing that any of those things exist. That is why the number of pictures this page can make is not the number of animations anyone wrote.

When a selection is too mixed for any single view, the stage splits into panels and draws each group with whatever fits it, so there is no combination that produces nothing. And whenever a view cannot use part of what you picked, it says so on the page rather than quietly dropping it.

What is not here

A few things that belong on a list like this are missing, and each is missing for a stated reason rather than for want of effort. Everything on this page is computed from the ephemeris and the rules the rest of the site uses; a quantity that would need a classical table this build cannot read is left out rather than guessed.
